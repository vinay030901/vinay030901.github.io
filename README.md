# Vinay Kumar — Portfolio

Static portfolio designed for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — project modals, mobile navigation, scroll effects

## Before publishing
1. Replace the LinkedIn `href="#"` in `index.html` with your real LinkedIn URL.
2. If you have a resume PDF, add it to this folder and add a Resume button/link.
3. Review project wording so every claim matches your actual work.

## GitHub Pages
Push these files to a GitHub repository, then open:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**

Your site will normally be available at:
`https://vinay030901.github.io/<repository-name>/`

If the repository is named `vinay030901.github.io`, the URL is:
`https://vinay030901.github.io/`
